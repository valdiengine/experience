# Exploration Capability

Exploration, Gamification and Eco Pokedex Layer transforms tourism into interactive discovery.

## Architecture

exploration.capability.js - Capability entry point
exploration.manager.js - Discovery registration and rewards
exploration.schema.js - Entity schemas and enums
exploration.events.js - Event definitions
pokedex/pokedex.manager.js - Species collection management
gamification/gamification.manager.js - Level progression and rewards
gamification/points.manager.js - Points tracking and calculation
missions/mission.manager.js - Mission definitions and progress
media/media.optimizer.js - Image processing and storage
leaderboard/leaderboard.manager.js - Leaderboard calculation

## Explorer Levels

Level 1: Explorer (0 points)
Level 2: Observer (200 points)
Level 3: Contributor (600 points)
Level 4: Guardian (1500 points)
Level 5: Ambassador (3500 points)

## Point Categories

- Exploration: places, destinations, routes
- Ecology: observations, conservation, species
- Community: memories, reviews, helping others
- Local Support: businesses, experiences, recommendations

## Dependencies

destination, community, ecology, public, pwa-engine, seo-intelligence, engagement, intelligence, observability
