# Roadmap Domain

> Where development is going. Planning and scheduling.

## Contents

| File | Purpose | Audience |
|------|---------|----------|
| `ROADMAP.md` | Master roadmap with all phases | Everyone |
| `CHANGELOG.md` | Chronological history of completed phases | Everyone |
| `RELEASE_PLAN.md` | Future milestones and release planning | Product, DevOps |
| `TECHNICAL_DEBT.md` | Known architectural limitations | Developers, Architects |

## How to Use This Folder

- **What's been done?** Check `CHANGELOG.md`
- **What's next?** Check `ROADMAP.md` or `docs/ai/NEXT_PHASE.md`
- **When will it ship?** Check `RELEASE_PLAN.md`
- **What's broken?** Check `TECHNICAL_DEBT.md`

## Relationship to Other Folders

- `docs/ai/` — Current implementation state (changes frequently)
- `docs/knowledge/` — Why the platform exists (ideas)
- `docs/architecture/` — How the platform works (technical)
- `docs/api/` — Communication contracts (reference)
- `docs/vision/` — Where the platform could evolve (inspiration)

This folder is **planning-focused**. It tracks progress, not implementation details.
