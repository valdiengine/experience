# P15.8.4 — PRESENTATION RUNTIME INTEGRATION

## Date: 2026-08-10

## Status: IMPLEMENTED

---

## Overview

P15.8.4 connects the Application Runtime (from P15.8.3) with the Presentation Runtime. It transforms RuntimeApplication into presentation-safe context that can be rendered.

**Location**: `web/application/`

---

## Architecture

```
HTTP Request
    ↓
ApplicationResolver
    ↓
RuntimeApplication
    ↓
ApplicationPresentationContext
    ↓
ApplicationPresentationAdapter
    ↓
PresentationViewModel
    ↓
PresentationRuntime (existing)
    ↓
HTML Response
```

---

## Components

### 1. ApplicationPresentationContext

Transforms RuntimeApplication into a presentation context.

**Responsibilities:**
- Transform runtime data to presentation format
- Determine rendering mode (WORDPRESS/HYBRID/EXPERIENCE)
- Determine content layer
- Extract branding, SEO, theme
- Extract capabilities and sections

**Location**: `web/application/application.presentation.js`

### 2. ApplicationPresentationAdapter

Transforms ApplicationPresentationContext into ExperienceViewModel-compatible format.

**Responsibilities:**
- Filter internal infrastructure references
- Ensure presentation-safe data
- Validate rendering context
- Map application data to view model

**Location**: `web/application/application.presentation.adapter.js`

### 3. ApplicationPresentationRenderer

Orchestrates the complete rendering pipeline.

**Responsibilities:**
- Coordinate all components
- Handle errors gracefully
- Return presentation result

**Location**: `web/application/application.presentation.renderer.js`

---

## Rendering Modes

| Mode | Description | Content Layer |
|------|-------------|---------------|
| WORDPRESS | WordPress renders everything | wordpress |
| HYBRID | Experience + WordPress content | hybrid |
| EXPERIENCE | Experience renders everything | experience |

---

## Security Boundaries

The presentation layer does NOT expose:
- Database connections
- Storage providers
- WordPress clients
- Credentials
- Internal configurations
- Provider instances

---

## Usage

```javascript
import { createApplicationPresentationRenderer } from './application/index.js'

const renderer = createApplicationPresentationRenderer()

const result = await renderer.render({
  domain: 'valdi.app',
  path: '/empresa/albasie'
})

if (result.success) {
  const presentation = result.presentation
  // Use presentation for rendering
}
```
