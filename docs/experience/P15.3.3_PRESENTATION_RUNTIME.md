## Overview

P15.3.3 implements the PresentationRuntime class that integrates the complete presentation pipeline from HTTP request to rendered experience.

---

## Architecture

```
Request → ExperienceRuntime → ExperienceContext
                              ↓
            PresentationAdapter → ExperienceViewModel
                                   ↓
                      ComponentResolver → Components
                                   ↓
                                   Renderer
                                   ↓
                         Rendered Presentation
```

## PresentationRuntime

Main orchestrator class for the presentation layer:

```javascript
class PresentationRuntime {
  async initialize()
  async render(request)
  async shutdown()
  async health()
}
```

### Methods

#### initialize()

Initializes the ExperienceRuntime and Presentation Core components.

#### render(request)

Renders a complete presentation for the given request.

**Request shape:**
```javascript
{
  hostname: 'valdi.app',
  path: '/',
  headers: {}
}
```

**Returns:**
```javascript
{
  requestId: 'uuid',
  metadata: { destination, domain, experience, isResolved, componentCount },
  identity: { platform, tenant, environment },
  destination: { slug, name, region, country },
  ecosystem: { modules, capabilities },
  company: { slug, name },
  experience: { type, config },
  modules: [...],
  capabilities: [...],
  branding: { logo, colors },
  theme: { mode, colors },
  navigation: { items },
  seo: { title, description },
  i18n: { locale, translations },
  maps: { provider, config },
  analytics: { trackingId },
  contact: { email, phone, address },
  sections: [...],
  modules: [...],
  components: { tree },
  rendered: { branding, navigation, seo, contact }
}
```

#### shutdown()

Gracefully shuts down the runtime.

#### health()

Returns health status of all subsystems.

## Security Boundaries

The PresentationRuntime enforces:

- **Tenant Isolation**: Each destination operates in isolation
- **Company Isolation**: No cross-tenant company data leakage
- **Database Boundary**: No direct storage access from components
- **Media Boundary**: No media API access from components
- **Internal Field Protection**: config, providers, request, resolution not exposed
