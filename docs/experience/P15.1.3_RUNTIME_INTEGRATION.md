### Registration

```javascript
engine.register('experience', ExperienceRuntimeIntegration, {
  version: '1.0.0',
  category: 'experience',
  dependencies: [],
  priority: 100,
})
```

### Initialization Step

```javascript
async #initializeExperience(engine, config) {
  const experience = engine.getModule('experience')
  if (experience) {
    await experience.initialize()
    this.#emit(BOOTSTRAP_EVENTS.EXPERIENCE_INITIALIZED, { status: 'initialized' })
  }
  return experience
}
```

## 8. Isolation

### Destination Isolation

- Each destination receives its own configuration
- valdi.app cannot receive natales.app branding
- Cache keys include destination identity

### Company Isolation

- Company context is scoped to destination
- Albasie company in Valdivia does not leak to Puerto Natales

### Cache Isolation

- Cache key includes: country, region, destination, company, experience
- Different destinations have separate cache entries
