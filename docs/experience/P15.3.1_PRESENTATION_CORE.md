## Components

### PresentationAdapter

Transforms `ExperienceContext` into a presentation-safe structure:

```javascript
const adapter = new PresentationAdapter()
const viewModel = adapter.adapt(experienceContext)
```

**Responsibilities:**
- Validates required presentation fields
- Protects internal fields (`config`, `providers`)
- Normalizes presentation-safe values
- Preserves destination, company, and experience identity

### ExperienceViewModel

Presentation-safe value object:

```javascript
const vm = new ExperienceViewModel(adaptedData)
vm.destinationSlug      // string
vm.experienceType       // string
vm.hasModule('gallery') // boolean
vm.resolveTitle()       // string
```

### ComponentRegistry

Maps sections and modules to presentation components:

```javascript
const registry = new ComponentRegistry()
registry.getSection('hero')    // { id: 'hero', name: 'Hero', type: 'section' }
registry.getModule('gallery')  // { id: 'gallery', name: 'Gallery', type: 'module' }
```

### ComponentResolver

Resolves which components to render:

```javascript
const resolver = new ComponentResolver(registry)
resolver.setViewModel(viewModel)
const { sections, modules } = resolver.resolve()
```

### Renderer

Core rendering abstraction:

```javascript
const renderer = new Renderer(resolver)
renderer.setViewModel(viewModel)
const rendered = renderer.render()
```

## Key Features

### Configuration-Driven

All presentation decisions derive from ExperienceContext configuration:

- `experience.sections` → rendered sections
- `modules` array → rendered modules
- `theme` → visual styling
- `branding` → logo, colors, fonts
- `navigation` → header, footer

### Destination Isolation

No hardcoded destination logic:

```javascript
// WRONG
if (destination === 'valdi') renderValdiUI()

// CORRECT
experience.sections.forEach(renderSection)
```

### Security

Internal fields are protected:

```javascript
// NOT exposed to presentation
context.config       // internal
context.providers    // internal
```
